# DaiLoiOS XFCE Configuration

Thư mục này chứa hai file cấu hình XFCE đã được DaiLoiOS tùy chỉnh.

## Thành phần

- `xfce4-desktop.xml`: cấu hình Desktop và hình nền mặc định.
- `xfce4-panel.xml`: cấu hình Panel, Menu Start và các biểu tượng trên thanh tác vụ.

## Nguồn gốc

Các file dựa trên cấu hình XFCE/Linux Mint XFCE và được DaiLoiOS điều chỉnh để sử dụng trong bản ISO.

Các thành phần XFCE gốc tiếp tục tuân theo giấy phép của dự án XFCE và Linux Mint.
