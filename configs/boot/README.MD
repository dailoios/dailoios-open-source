
# DaiLoiOS Boot Configuration

Thư mục này chứa các cấu hình và tài nguyên khởi động đã được
DaiLoiOS tùy chỉnh.

## Thành phần

- Theme GRUB.
- Hình nền và logo menu khởi động.
- Theme Plymouth.
- Cấu hình tên hệ điều hành trong menu boot.

## Nguồn gốc

Các thành phần dựa trên GRUB, Plymouth và cấu hình Linux Mint,
sau đó được DaiLoiOS điều chỉnh về tên, logo và hình ảnh nhận diện.
