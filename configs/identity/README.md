# DaiLoiOS System Identity

Thư mục này chứa các file nhận diện hệ điều hành DaiLoiOS.

DaiLoiOS được xây dựng trên nền Linux Mint 22.3 Zena và Ubuntu
24.04 Noble, sau đó được tùy chỉnh về tên gọi, giao diện, phần mềm
và cấu hình hệ thống.

## Thành phần

- `os-release`: thông tin nhận diện hệ điều hành theo chuẩn Linux.
- `lsb-release`: thông tin nhận diện dành cho các công cụ LSB và
  phần mềm tương thích.

## Vị trí cài đặt

```text
/etc/os-release
/etc/lsb-release
