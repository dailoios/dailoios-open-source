
# DaiLoiOS Scripts

Thư mục này chứa các tập lệnh do dự án DaiLoiOS tự phát triển hoặc
tự chỉnh sửa để cấu hình và xây dựng hệ điều hành DaiLoiOS.

## Nội dung dự kiến

- Script cấu hình giao diện XFCE.
- Script tắt Linux Mint Welcome.
- Script cấu hình repository DaiLoiOS.
- Script cài đặt phần mềm mặc định.
- Script tạo biểu tượng ngoài Desktop.
- Script ghim ứng dụng lên thanh tác vụ.
- Script cấu hình máy in.
- Script cấu hình Wine và Bottles.
- Script chuẩn bị hệ thống trước khi đóng ISO.
- Script hậu cài đặt cho các gói `.deb`.

## Quy định

Chỉ đưa vào thư mục này những script:

- Do DaiLoiOS tự viết.
- Hoặc đã chỉnh sửa từ nguồn khác và có ghi rõ nguồn gốc.
- Không chứa mật khẩu, API key hoặc thông tin máy chủ bí mật.
- Không chứa phần mềm thương mại hoặc nội dung không có quyền phân phối.

## Giấy phép

Các script do DaiLoiOS tự phát triển được phân phối theo giấy phép
ghi trong file `LICENSE` của kho mã nguồn, trừ khi từng file có ghi chú khác.
