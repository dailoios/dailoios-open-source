# DaiLoiOS Update Suite

Gói này điều chỉnh cơ chế cập nhật trong DaiLoiOS.

## Chức năng

- Vô hiệu hóa Mint Update tự khởi động.
- Vô hiệu hóa launcher mặc định của Mint Update.
- Dừng các tiến trình Mint Update đang chạy.
- Tránh chạy đồng thời Mint Update và cơ chế cập nhật của DaiLoiOS.
- Duy trì thông báo cập nhật tối thiểu theo cấu hình DaiLoiOS.

## Phiên bản

`1.0.1`

## Lưu ý

Gói này không loại bỏ nhu cầu cập nhật bảo mật của hệ thống.
DaiLoiOS vẫn phải cung cấp cơ chế cập nhật thay thế thông qua APT,
repository hoặc công cụ DaiLoi System Update.

Linux Mint Update vẫn thuộc bản quyền và giấy phép của dự án Linux Mint.
