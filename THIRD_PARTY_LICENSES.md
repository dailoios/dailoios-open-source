# Giấy phép thành phần bên thứ ba

DaiLoiOS được xây dựng dựa trên nhiều dự án phần mềm mã nguồn mở.

Danh sách này sẽ tiếp tục được cập nhật theo từng phiên bản phát hành.

## Nền tảng hệ thống

| Thành phần | Nguồn dự án | Giấy phép |
|---|---|---|
| GNU/Linux | GNU và cộng đồng Linux | Nhiều giấy phép, chủ yếu GPL |
| Linux Kernel | Linux Kernel Project | GPL-2.0-only |
| Linux Mint | Linux Mint Project | Theo từng gói thành phần |
| Ubuntu packages | Ubuntu Project | Theo từng gói thành phần |
| Debian packages | Debian Project | Theo từng gói thành phần |
| XFCE Desktop | XFCE Project | GPL, LGPL và giấy phép liên quan |
