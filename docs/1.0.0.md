# DaiLoiOS 1.0.0 – Ghi chú phát hành

Ngày phát hành dự kiến: 2026  
Trạng thái: Bản phát hành đầu tiên

DaiLoiOS 1.0.0 là phiên bản đầu tiên được xây dựng trên nền Linux Mint 22.3 XFCE, hướng đến người dùng Việt Nam, cửa hàng máy tính, trung tâm đào tạo và kỹ thuật viên sửa chữa.

> DaiLoiOS không phải là sản phẩm chính thức của Linux Mint, Ubuntu, Debian, Canonical hoặc XFCE.

## 2. Điểm mới chính

### Nhận diện DaiLoiOS

- Đổi tên hiển thị hệ điều hành thành DaiLoiOS.
- Thêm thông tin website và hỗ trợ DaiLoiOS.
- Giữ thông tin tương thích với Linux Mint, Ubuntu và Debian.
- Thay logo hệ thống và biểu tượng Menu Start.
- Thay hình nền Desktop mặc định.

### Giao diện XFCE

- Điều chỉnh bố cục XFCE Panel.
- Cấu hình Menu Start bằng Whisker Menu.
- Thay biểu tượng nút Start bằng logo DaiLoiOS.
- Thiết lập hình nền Desktop riêng.
- Đồng bộ giao diện cho người dùng mới.

### Màn hình đăng nhập

- Đưa khung đăng nhập và ô nhập mật khẩu vào giữa màn hình.
- Đồng bộ hình nền và nhận diện DaiLoiOS.
- Giữ nền tảng Slick Greeter của Linux Mint.

### Khởi động hệ thống

- Thay hình ảnh khởi động Plymouth bằng nhận diện DaiLoiOS.
- Giữ cấu trúc theme `mint-logo` để tương thích với cấu hình hiện tại.
- Điều chỉnh hình ảnh hiển thị trong quá trình khởi động.

### Linux Mint Welcome

- Vô hiệu hóa Linux Mint Welcome tự khởi động.
- Không hiển thị màn hình chào Mint sau khi người dùng đăng nhập.

### Repository DaiLoiOS

Repository chính thức:

```text
http://14.225.210.88:8081
```

Distribution:

```text
zena
```

Components:

```text
main drivers fonts printer tools pro beta
```

Repository được sử dụng để phân phối ứng dụng, driver, font chữ, công cụ hệ thống và các gói cập nhật của DaiLoiOS.

## 10. Hạn chế đã biết

Một số thiết bị hoặc phần mềm có thể cần cấu hình bổ sung:

- Một số máy in Canon, đặc biệt Canon LBP2900.
- Một số ứng dụng Windows chạy qua Wine hoặc Bottles.
- Một số driver thiết bị đặc thù.
- Một số máy có phần cứng quá mới hoặc quá cũ.
- Repository hiện có thể còn sử dụng chế độ `Trusted: yes` trước khi triển khai khóa ký APT chính thức.

Người dùng nên sao lưu dữ liệu trước khi cài đặt hoặc nâng cấp.

## 12. Tải xuống và xác minh

File ISO chính thức nên được cung cấp trên website DaiLoiOS.

Mỗi bản phát hành nên công bố:

- Tên file ISO.
- Dung lượng.
- SHA256.
- Ngày phát hành.
- Kiến trúc.
- Ghi chú phát hành.

Ví dụ kiểm tra SHA256:

```bash
sha256sum DaiLoiOS-1.0.0-amd64.iso
```

Không tải ISO từ nguồn không rõ ràng.
